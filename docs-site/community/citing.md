# Citing anonlib

If anonlib is useful in your work, please cite the software and, for the method, the paper.

**Software** (concept DOI, resolves to the newest release):

> author, A. *anonlib: bitwise-identical GPU machine learning in Mojo on Apple Metal, NVIDIA CUDA and AMD HIP.*
> [doi:DOI-WITHHELD](DOI-WITHHELD)

**Paper:**

> author, A. *Bitwise-Identical Machine Learning Across Metal, CUDA, and HIP.* Preprint, October 2026.
> [PDF](https://anon.example/paper.pdf)

The repository's [CITATION.cff](https://github.com/anon/anon/blob/main/CITATION.cff) has the
machine-readable record.
