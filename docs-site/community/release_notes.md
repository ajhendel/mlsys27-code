# Release notes

Each release's changes, wheel contents and bit changes are in the repository's
[CHANGELOG](https://github.com/anon/anon/blob/main/CHANGELOG.md). Packages are on
[PyPI](https://pypi.org/project/anonlib/#history), and every release is archived on
[Zenodo](DOI-WITHHELD).

Because `identical` output bits can change between releases, note the release with any result you need to
reproduce, and compare results within one release.
